### Para el módulo de **Productos**, aprendí a estructurar la arquitectura MVC desde cero conectando el modelo (`producto.php`) a la base de datos MySQL mediante PDO para consultar la tabla con `SELECT * FROM producto`, procesar esos datos desde el controlador (`productoControllers.php`) almacenándolos en la variable `$productos`, y enviarlos a la vista (`index.php`) para desplegar el catálogo dinámicamente en una tabla HTML con su nombre, precio y categoría.

### Para el módulo de **Clientes**, apliqué la misma lógica MVC creando el modelo (`cliente.php`) para extraer los registros de clientes y el controlador (`clienteController.php`) para gestionarlos y pasarlos a la vista (`index1.php`), donde estructuré una tabla con ID, nombre, documento, correo y teléfono; logrando además integrar ambos módulos desde el punto de entrada principal (`public/index.php`) para mostrar ambas listas en pantalla y resolviendo problemas clave como el manejo de rutas en minúsculas y la selección de la base de datos en phpMyAdmin con `USE gestion_productos;`.
